What it does

The planner lets you create study tasks (sprints) and drag them across three columns: Next Sprint, Curent Sprint and Sprinted. Everything is saved to localStorage so your boards will be preserved between sessions.

Priority system

Each sprint gets one of six colore-coded prioritie, defined as CSS variables:


Priority 0 Priority 1 Priority 2 Priority 3 Priority 4 Priority 5
--pr0-color: #A52B35; --pr1-color: #E78738; --pr2-color: #F4C617; --pr3-color: #E6E02B; --pr4-color: #3084A3; --pr5-color: #4EA24D;

How data is stored

Every sprint is a plain object with four fields. The whole board is one JSON array in localStorage under the key 'sprints':

{ name: 'ASD Test', description: 'Some desc', priority: 2,} saveSprints(array) loadSprints()

When a sprint is dragged to a new column, sprints[draggedIndex].column is updated and saveSprints() is called immediately — no server, no sync delay.

Drag and Drop

Drag-and-drop uses the native HTML5 API. The dragged card's priority level is read from its .priority-circle to paint the drop zone in the matching color:

column.addEventListener('dragenter', function(event) { let level = draggedCard .querySelector('.priority-circle').textContent; content.classList.add( 'drag-over', 'drag-over-' + level + '' ); });
